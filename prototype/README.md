# 哆啦的故事书 · 本地运行与提交说明

## 快速启动

在 prototype 目录运行：

    python server.py

打开 http://127.0.0.1:4173/ 。操作员页：http://127.0.0.1:4173/?operator=1 。支持 Python 3.10+，无需安装 Python 第三方依赖或前端依赖。新版必须用 server.py 启动，旧的 python -m http.server 只支持静态演示，无法提供分析接口。

## 按住说话的流程

按下：停止哆啦朗读、暂停自动演示、开启麦克风；实时显示识别文字。
松手：结束收音，等待识别最终结果，只提交一次文字。
分析：将文字、当前物品与轮次发送到本地 /api/analyze。最多保留三组临时对话上下文，刷新或重来清空。
回复：屏幕同时显示孩子的话与哆啦的回复，声音开启时会朗读。
孩子提问或聊天：回答后停在本轮，可以继续说。
回答教学问题：回复结束并短暂停留后，接续下一轮预设英文。
没有声音：温柔提示重试，不伪造文字、不强制跳轮。
出错或超时：明确标注“本地演示回复”，原有操作员控制仍可接管。
切换场景、重来或操作员接管：取消收音和等待中的回复，丢弃过期结果。

原有英文词、三轮问题、短句、卡片与绘本英文内容未修改。模型只生成中文交流回复。

## 云端模型与密钥隔离

当前服务接入阿里云百炼 qwen3.8-flash。默认北京接口 https://dashscope.aliyuncs.com/compatible-mode/v1 。接口与密钥所属地域必须一致，可在配置时更换为其他地域或业务空间专属地址。

在你自己的终端运行：

    python configure_cloud.py

前两项按回车使用北京接口和 qwen3.8-flash；第三项输入 API Key，输入不会显示。不要在聊天、前端代码或提交材料中粘贴密钥。

配置保存在项目目录外：Windows 为 %LOCALAPPDATA%/DuolaStorybook/cloud.json，密钥使用 Windows DPAPI 按当前用户加密；其他系统为 ~/.config/DuolaStorybook/cloud.json，权限为 600。配置完成后服务会在下次请求重新读取，不必重启。

也支持服务器环境变量 DUOLA_API_KEY、DUOLA_BASE_URL、DUOLA_CLOUD_MODEL；后两项缺省为北京接口与 qwen3.8-flash。新设置的环境变量需要服务进程重新启动后才生效。

网页只请求本机 /api/analyze。服务器携带密钥请求百炼，前端、接口响应、日志和提交压缩包均不包含密钥。服务只绑定本机 127.0.0.1，拒绝其他来源的请求。密钥不会发送给模型作为提示词，也不允许认证请求跟随重定向。

模型只回复简短中文并判断当前交流意图；预设英文教学内容由页面固定流程管理，不交给模型改写。屏幕标注“云端回复”，失败或未配置则标注“本地演示回复”。无密钥时不会声称已连接大模型。

服务器不保存识别文字或录音。云端分析会把识别文字、当前教学上下文及最多三轮临时对话发送给百炼；不会传送原始录音和照片。浏览器 SpeechRecognition 还可能使用浏览器供应商的在线转写服务。

接口异常、超时、无权限或未配置时，原型仍能用本地内容演示。密钥配置工具不测试 API，不会输出密钥；配置后请通过操作员文字入口验证云端回复。

参考官方文档：
- https://help.aliyun.com/zh/model-studio/qwen3-8-flash
- https://help.aliyun.com/zh/model-studio/base-url

## 演示操作

- 下一步：N / 右方向键；上一步：B / 左方向键。
- 对话模拟回应：1 英文 / 2 中文 / 3 沉默。
- M 神秘卡；A 自动演示 / 暂停；R 重来。
- 首页支持鼠标拖动旋转公园、滚轮缩放、恢复视角；进入教学后恢复固定镜头。鸭子、斑鸠、蜗牛、哆啦与蜘蛛沿各自路径移动。
- 七幕顶部可跳转；操作员面板支持九样物品与模拟识别文字。
- 顶部音符开启系统朗读，默认静音。
- 操作员与展示页需在同一浏览器、同源页面中打开，BroadcastChannel 不支持跨电脑同步。
- 图鉴只显示实际收集项，无需填写、补齐或选择；全部收集项自动进入绘本。
- 公园中哆啦兔子与可爱的小蜘蛛陪伴；绘本使用同一组本地矢量角色。
- 2D / 3D 按钮手动切换；WebGL 不可用时自动退回本地插图。

## 文件

index.html / style.css：画面与布局。
app.js：七幕控制与固定英文课程。
voice.js：语音状态、服务端分析请求、中文回复与流程衔接。
scene.js / vendor：离线 3D 场景、角色与 Three.js MIT 许可证。
content.json：服务端使用的固定课程上下文，与前端数据一致。
server.py：本地预览和百炼适配，无外部 Python 依赖。
cloud_config.py / configure_cloud.py：项目外配置与密钥保护；后者供用户在本机输入密钥。
verify*.cjs：开发验证脚本，仅依赖开发机已有 Playwright，不进入提交包。

当前绘本是本地矢量示意图，声音是系统朗读；拍照与识别仍为预设演示。未加入真实摄像头识别、用户账号或儿童数据持久化。


### 自由探索与素材（2026-10-11）
- 第 2–5 幕可拖动旋转、滚轮缩放公园，并从九种预设发现切换焦点；每种卡只收藏一次，可随时回家，手动模式不再两张即结束。自动演示仍以四张卡演示完整流程。
- design 原图复制到 assets，日夜双图在网页中分别展示，鸭子和蜗牛使用独立日夜图。草坪、湖泊及神秘卡保留矢量插图。原始素材不修改。

- 云端请求包含孩子语音文字、阶段、可信公园描述、当前卡片细节、已收集卡片及最近对话。描述由服务端资料生成；不上传音频或图片。提示要求具体的哆啦行为与观察邀请，避免空泛夸奖；动态回复不改固定英文课程。
- 绘本每页一句中文、紧接一句英语，真实回顾和明确标注的想象分别展示；所有页面描述哆啦的观察、比较、倾听或想象行为。
- 验证：node prototype/verify-exploration.cjs（项目根目录）；python prototype/verify_cloud.py；node prototype/verify-live.cjs（需云端配置与本地服务）。

动态回复：先回应，再提出一个适合4–6岁孩子的具体问题；鼓励指认、比较、寻找，不强迫回答。前端记录最近实际展示的五个课程词，服务端校验白名单；模型可唤醒其中一个词，不改写固定英文课程，不引入新英语词。云端遗漏问句时补充当前卡片的具体观察问题，本地回退同样保留一个问题。

助手与领卡：手机出门/对话使用 design 中 Bunny 表情素材，哆啦仍为产品名称。助手位于卡片前层；倾听/思考切换好奇表情，开启声音时嘴型随朗读开始与结束运动（节奏动画，非音素级口型）。三轮对话后保持待领卡状态，点击小按钮后播放 850ms 收藏动画，才将卡片和地图星星计入今天；切换发现或重置会取消未完成的动画。自动演示模拟点击确认。验证：node prototype/verify-assistant.cjs。
