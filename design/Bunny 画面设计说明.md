# 哆啦 · 画面设计说明

依据《哆啦 公园探险 · Demo 需求文档 v1.0》完成。此稿保留比赛原型规定的“发现—拍照—三轮对话—得卡—图鉴—睡前绘本”流程，没有用此前产品建议替换需求。

## 视觉方向：一座可以装进口袋的秋日公园

采用奶油纸底、苔绿主色、桂花金提示与靛蓝夜景。中央场景是一座黏土感低多边形公园微缩模型；手机像随身的小窗口，iPad 像一本打开的发现之书。整体避免游戏 HUD 的强刺激，保持轻、安静、温暖。

色彩：纸白 #F6F3E9、墨绿 #343E30、苔绿 #58704A、桂花金 #D8AA59、夜蓝 #202C46。主按钮使用苔绿，金色表示发现与记忆星星。夜晚设备内页面保留暖纸色，读完转深黑蓝。

## 七幕构图

1. 出门：下午全景，左侧主标题，右侧手机上的 哆啦 发出邀请。
2. 发现：镜头平滑移向物品，浮动标签标识空间位置。
3. 拍照：手机切取景界面，中心大快门按钮，按住说话作为另一入口。
4. 对话：哆啦、物品图形与英文词居中呈现；圆点显示三轮进度，回应提示保持温和。
5. 得卡：纸质卡片翻开，场景拉远，真实位置出现星星。
6. 回家：客厅窗景延续公园空间，手机变横屏 iPad，卡片可滑动、可选择。
7. 睡前：整体转靛蓝，暖色绘本一图一句；用过渡页明确进入想象，读完关灯，回到夜晚记忆地图。

## 信息层次

- 顶部七幕是给演示者和评委的流程定位。
- 公园、角色、设备插图是主视觉；儿童界面尽量通过图形和声音理解。
- 左侧短句说明当前体验，左下两行解释设计意图。
- 底部演示工具与儿童模拟界面分开。正式投屏可全屏，操作员另开窗口。

## 交互规范

设备内主按钮不小于 48 CSS px，快门 76px；儿童操作集中在图鉴卡片与播放按钮。保留键盘焦点、按钮语义与减少动态效果偏好。移动端将设备置于标题下方，平板模式保持横向绘本。

此版本为可体验的设计原型，正式比赛仍需替换预合成音频、补齐水彩绘本图组，并在会场做真实帧率与儿童参与彩排。
